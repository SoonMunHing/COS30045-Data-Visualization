Exercise 4.1 – SVG House and Garden

A picture built only from SVG primitives: rect, circle, ellipse, line, polyline, polygon, path and text. The SVG is 800 × 500 pixels. The origin (0, 0) is the top-left corner, x increases to the right and y increases downwards.

Understanding the SVG coordinate system

Each screenshot below highlights one example of a shape type (dashed red outline) and labels the coordinates from the code at the matching points in the drawing. The faint grid lines are every 100 px.

Use of AI

I used Claude (Anthropic) to help with this exercise. It generated a first version of the house and garden SVG, grouped the two windows inside a <g> positioned with transform="translate(…)", and produced the annotated coordinate screenshots by rendering the page in a headless browser and overlaying labels. I checked every coordinate against the code, customised the picture (colours, strokes, positions) and wrote the explanations in my own words.
